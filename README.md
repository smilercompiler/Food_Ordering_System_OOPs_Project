# 🍽️ Food Ordering System (OOPs Project in Java)

This is a Java-based food ordering system built using **Object-Oriented Programming (OOP)** principles and **Java Swing** for the GUI. It allows users to sign up, log in, browse a menu with dietary filters, add items to a cart, and place mock payments. An admin panel is also available to manage the menu.

---

##  Features

-  User registration and login (with file-based authentication)
-  Admin login with hardcoded credentials
-  View and filter menu items (e.g., lactose-free, nut-free)
-  Add items to cart
-  Simple mock payment functionality
-  Admin can add/remove menu items
-  Uses Java file I/O for data persistence

---

##  Technologies Used

- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)
- File Handling (no database)

---
